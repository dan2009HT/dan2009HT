# Code of Conduct

Soyez respectueux et bienveillant. Ce dépôt suit un code de conduite simple :

- Traitez les autres avec respect.
- Les comportements discriminatoires ou harcelants ne sont pas tolérés.
- Respectez les décisions des mainteneurs.

Pour signaler un comportement inapproprié, ouvrez une issue ou contactez le mainteneur.
